How to use an online simulator

  1. Click a patient’s picture or select Run online.
  2. Allow microphone access when the simulator requests it.
  3. Use Iraqi Arabic for Sameer Adnan. Mariam Hassan supports both English and Iraqi Arabic. For Sameer Saieed, conduct the dialogue in Arabic and present the examination findings in English. Use English for Sarah Miller and Suzan Ahmed.
